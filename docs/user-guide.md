# SubGauge 使用说明

## 启动

安装版：运行安装程序，安装到当前 Windows 用户后从开始菜单启动。

免安装版：解压后运行 `SubGauge.exe`。需要 Windows WebView2 Runtime；缺少时请从 Microsoft 官方安装。两种版本共用当前用户的账号与设置，免安装文件不包含登录凭据。

安装版发现缺少 WebView2 时会联网下载并安装运行时；离线电脑应提前安装 WebView2。安装程序不携带离线运行时。

安装目录和免安装 ZIP 随附 `LICENSE`、`THIRD-PARTY-NOTICES.txt` 与 `RUST-STANDARD-LIBRARY-NOTICES.html`，分别提供项目许可证、第三方声明和 Rust 标准库声明。

## 登录自启与快捷键

0.1.9 起，进入“详细用量 → 应用设置 → 启动与快捷键”，勾选“登录 Windows 后自动启动”，点击“保存启动设置”。默认关闭，仅安装版可登记；当前 Windows 用户登录后按所选方式显示浮窗或仅进入托盘。后台同步继续运行，手动启动或更新后重启仍显示浮窗，重复登录启动不打扰已有实例。

勾选表示启动项已登记，Windows 仍可在任务管理器或“启动应用”里单独禁用。页面提供“Windows 启动应用设置”入口；SubGauge 不会在每次启动时重新登记或覆盖系统的禁用选择。免安装版不改变安装版的启动项。

安装版和免安装版均可启用全局显示/隐藏快捷键，默认关闭。可输入 `Ctrl+Alt+G` 等组合，至少含 Ctrl 或 Alt，可加 Shift，再配字母、数字或 F1～F11。保存后生效，冲突会明确提示并保留原快捷键；重启时被其他软件占用不会阻止应用运行，可到设置里换一个组合。开发模式不注册真实全局快捷键。

内置升级保留原目录的自启登记；普通卸载只清理当前目录的启动值。手动升级选择先卸载时会清理自启，安装后需重新开启。安装器不删除账号与设置数据。

## 连接账号

首次启动点击小卡片的“连接账号”；已有账号时，从账号菜单进入“账号管理”，再点击“添加账号”。填写 Sub2API 站点地址、邮箱和密码。管理员和普通用户使用同一入口，默认查看自己的全部 Key 用量。如果站点要求 TOTP，继续填写动态验证码。

“记住登录”会将会话凭据绑定当前 Windows 用户加密保存，不保存密码。未记住的会话在退出后需要重新登录。站点验证码或定制接口不受支持时会明确提示，不会用示例数据冒充真实结果。

## 使用卡片

- 点击账号名称切换，显示设置按账号保存。
- 统计范围支持今日、最近 7 天、本月、最近几分钟。
- 本月从 1 日零点累计；最近 7 天为滚动 168 小时，与套餐账期无关。
- 展开查看最近一笔与最近几分钟；“详细用量”打开趋势、记录和分析。
- 余额一直是当前值，不随统计范围变化。
- 顶部齿轮打开当前账号的显示设置，可选择指标、排序和默认范围；详情右上角的应用设置调整主题、背景透明度和置顶。
- 卡片底部的图钉切换浮窗置顶，托盘“浮窗置顶”提供相同开关；它是应用设置，切换账号不改变。置顶不影响详情窗口。
- 顶部的减号按钮将浮窗隐藏到托盘，后台同步继续；左键点击托盘图标或使用“显示浮窗”恢复。

0.1.5 起可拖动浮窗四边或四角调整大小，命中区域在卡片外侧的透明留白内。小卡片和展开态分别记忆尺寸。仅左右拖动仍保持自动高度，仅上下拖动保留宽度。最小高度保证指标和操作可见，较矮展开态在展开区域内滚动；内容变化可能临时撑高，菜单临时扩窗不会改写保存尺寸，菜单打开时先关闭菜单再拖边。

0.1.7 起通过顶部拖动柄移动浮窗，拖动过程中可以跨越屏幕接缝，松手后调整到目标屏幕的工作区。原地展开后收起恢复原小窗位置和大小；展开后主动移动，再收起会留在新位置。显示器断开或工作区变化后会尝试恢复到可用位置，托盘“显示浮窗”也会重新检查。混合缩放和真实双屏的验收范围见验证记录。

应用设置里的“恢复默认尺寸”同时重置小卡片和展开态为默认宽度、自动高度，不影响账号、指标和范围。默认宽度为 316 个逻辑像素，可调宽度通常为 280～640，屏幕可用空间较小时以工作区为准。

应用设置提供浅色、深色和跟随系统，默认浅色；主题对所有窗口生效，重启后保留。透明度只调整浮窗背景，文字和菜单保持清晰。详情窗口可以最小化，重新从卡片或托盘打开详情时会恢复已有窗口。

应用设置仅保存修改过的字段。其他窗口或托盘改动了正在编辑的同一字段时，未保存的修改会保留，并要求再次确认；操作失败会显示原因，不把失败当作已保存。

新账号默认显示今日的扣费、请求数、Token 和缓存率；统计时区固定为 `Asia/Shanghai`，可在账号显示设置中修改。最近窗口默认 5 分钟，当前界面允许 1～120 分钟。上游账号可以手动改为最近 7 天，并加入当前余额。

默认最近请求每 10 秒同步，余额与范围汇总每 30 秒同步，后台账号每 120 秒同步；应用设置可调整。卡片同步在限流或网络失败时按退避策略重试，卡片手动刷新也不会越过限流等待期。

“实时”表示服务端记录更新后进行同步，请求尚未落库时不会提前出现在用量中。网络失败时旧数据保留并标记；数据不完整时不要当作最终总计。

滚动范围的请求列表会显示本次截止时间。翻页使用同一时间窗口；超过 60 秒或记录变化时，点击“刷新第一页”重新读取。卡片仍独立更新全部 Key 汇总。模型与 Key 分析按需读取，Key 明细超过读取上限时会说明数据不完整。

图表显示独立的更新时间与统计起止范围；普通打开页面可复用最多 5 分钟缓存，点击“立即刷新”会重新读取。

0.1.10 起，请求页上方使用紧凑的全部 Key 汇总。模型、Key 输入框可以按名称搜索，选择后点击“筛选”；候选接口暂不可用时，也可输入精确模型名或数字 Key ID，按 Enter 确认。清除输入框只修改筛选草稿，点击“筛选”应用，或用“重置”恢复全部记录。模型与 Key 分析按实际扣费从高到低排列，点击项目会进入相应请求。筛选不改变卡片或顶部的全部 Key 总计；点击请求行或右侧箭头展开详情，选中文本不会展开。

趋势中的柱间距对应时段，悬停或按 Tab 可查看费用。站点未返回的时段显示未确认标记，不能视为零；只有完整明细聚合才会将中间的空时段确认为零。服务端未提供分桶时区时，图表保留站点原始时间并明确提示，不擅自按电脑时区换算。

0.1.4 起，记录、分析和后台同步共用账号的等待期；限流后已有数据保留并标记过期，已缓存图表可继续查看。等待期内强制刷新也不发出该账号的新请求，其他账号不受影响。

## 退出与数据

关闭详情窗口不退出程序。关闭浮窗会隐藏到托盘；左键点击托盘图标或使用菜单“显示浮窗”恢复，菜单“退出 SubGauge”才结束程序。再次启动任一种版本也会恢复已有实例。登录失效只影响对应账号，可以重新登录，其他账号继续使用。

配置位于 `%LOCALAPPDATA%\app.subgauge.desktop`：`accounts.v1.json` 包含账号、设置、加密会话和最后成功快照；`window.json` 保存浮窗位置及两种状态的逻辑尺寸；`updates.v1.json` 保存更新偏好及安装尝试。旧版位置文件升级时自动迁移，默认维持自动高度。账号凭据不能直接复制给其他 Windows 用户或电脑使用。安装版与免安装版共享此目录。

0.1.9 的 `desktop.v1.json` 仅保存登录启动的显示方式和快捷键，不含凭据；启动登记本身以 Windows 中的实际记录为准。文件损坏或来自未来版本时会保留原文件并提示，不静默覆盖。

鼠标移到同步状态可查看用量、余额、最近窗口分别多久前更新；正常结果超过对应刷新间隔三倍且至少 90 秒时标记未更新。异常、部分数据或需登录状态继续显示原原因。指标悬停提供完整费用、请求数、Token 组成和缓存率计算说明。

0.1.10 起，用量、余额、最近窗口和最近一笔分别跟踪状态。收起卡片只依据正在显示的指标提示，展开后再纳入最近数据；最近窗口待补齐不等于今日汇总也不完整。卡片展开态可展开同步说明，详情页点击范围旁的状态查看各项原因。非零费用小于 $0.01 时增加小数位，极小值显示 `<$0.0001` 等界限，完整精度仍见悬停说明。

本应用当前不计算套餐结转、剩余额度或跨站合计。费用使用服务端个人实际扣费；Token 包括普通输入、输出、缓存读取和缓存写入。缓存率为缓存读取 /（普通输入＋缓存读取＋缓存写入），不包含输出，也不平均单笔百分比；分母为零显示“—”。

## 内置更新

0.1.8 起，可在“详细用量 → 应用设置 → 软件更新”或托盘“检查更新”查看当前版本及预览渠道。默认启动后延迟检查，随后最多每日一次；自动检查可以关闭。后台只检查，不自行下载、安装或中断用量同步。发现新版时，托盘菜单会显示版本提示，跳过该版本后不显示此提醒。

安装版点击“下载更新”后显示进度，完整下载并验证签名与公告版本一致后，点击“安装并重启”，再确认安装。程序先等待正在进行的账号操作或同步，并保存账号、设置和窗口位置，再退出并启动安装器。请先结束浮窗拖动或缩放。安装器使用当前安装目录，账号数据仍保存在独立用户数据目录。

下载或安装准备失败可重试；签名不符不会安装。安装器启动后的错误由安装界面报告，应用不保证自动回滚；需要时重新打开旧版或从“打开发布页”手动修复。重新启动会检查上次尝试的预期版本。重新检查会清除当前进程缓存的下载；后台与托盘检查则保留已下载文件。

免安装版提供“下载 ZIP”发布页，需要退出后解压更新；开发版不调用安装器。“稍后”暂时收起更新说明，“跳过此版本”保存提醒偏好，手动检查仍可查看并下载。下载缓存仅保留在当前进程内，退出后需要重新下载。

公开更新渠道在签名附件与清单发布后才可用；发布前或 GitHub 无法连接时明确显示检查失败，不将失败显示成“已是最新”。0.1.6 和 0.1.7 没有更新模块，第一次升级到 0.1.8 仍需手动安装。

## 升级与卸载

升级前先在托盘菜单选择“退出 SubGauge”，包括从 ZIP 启动的旧实例。关闭详情或隐藏浮窗不会退出。之后运行新安装包，或将新 ZIP 解压到独立目录并启动；正常升级保留当前 Windows 用户的共享账号与设置。

安装程序只检查安装目录里运行的程序，不能替你退出另一目录的免安装版。旧实例仍运行时，启动新版会恢复旧实例，不能据此确认已经运行新版。

卸载前同样先通过托盘退出正在运行的安装版或免安装版，再从 Windows 的应用列表卸载。卸载默认保留用户数据；只有主动勾选“删除应用数据”才清除共享配置。此选项同时影响安装版和免安装版的账号、登录状态、显示设置及窗口位置，不会删除站点上的账号或用量记录。免安装版以后启动会需要重新连接和设置。

不要在免安装实例仍运行时清除共享数据，后台同步保存可能再次创建配置。需要验证清空行为时，应使用独立 Windows 测试用户和测试账号，不使用日常真实用户配置。
