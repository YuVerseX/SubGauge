# SubGauge 验收清单

本页定义执行条件和记录方式，不重复版本结果。已通过与未执行项目见 [验收摘要](validation.md)；新版本必须记录自己的证据，不能沿用旧版的资源、安装或鼠标检查。

## 执行与记录

1. 运行业务回归、布局检查、类型检查、Rust 格式和严格 Clippy。
2. 对最终 Release 验证原生窗口、同步和生命周期，区分 API 检查与真实鼠标操作。
3. 在隔离测试环境验证安装、升级、共享配置和卸载；缺少运行时的场景使用独立系统。
4. 在实际设备条件具备时补测系统、DPI、多屏和睡眠恢复。
5. 需要资源验收时单独安排纯空闲和操作观察，记录实际时长；不能用包含构建、测试或用户操作的记录代替纯空闲。

每次报告版本、安装版或 ZIP、进程路径、系统和 WebView2 版本、实际 DPI、屏幕工作区、账号类型、操作步骤、时间范围、结果及限制。公开报告使用匿名账号，不包含站点身份、凭据、私有用量或原始配置。

网络中断、限流、会话失效和慢响应优先使用本地接口夹具；真实核对按各账号个人接口进行，不修改真实站点策略。

## 同步与统计

| 场景 | 通过条件 |
| --- | --- |
| 账号切换与慢响应 | 当前身份、范围与数值一致；旧账号或旧范围响应不覆盖当前页面，单账号失效不影响其他账号 |
| 限流退避 | 同账号记录、分析、后台和强制刷新共用等待期；等待期间不发新请求，已有数据标记过期，缓存可读，另一账号继续工作，到期后恢复 |
| 网络中断与恢复 | 保留最后成功数值及各自时间，显示失败；恢复后补同步，不积压轮询或回退为示例数据 |
| 最近窗口 | 无新记录时，过期记录自然离开窗口；零用量、零缓存分母和未完成覆盖显示明确 |
| 日期与时区 | 今日、自然月和滚动 168 小时的跨日、跨月、闰年及 DST 边界正确 |
| 分页与落库 | 重复、变动和延迟记录按 ID 处理；无法确认完整覆盖时标记不完整，过期滚动列表可重新读取 |
| 余额与统计核对 | 以相同账号、时区和范围分别核对；余额为当前快照，费用与四项 Token 可复算；新增请求和采样延迟单独说明 |
| 会话恢复 | 记住登录后重启恢复；未记住、解密失败或失效只影响对应账号，凭据不进入前端和日志 |
| 睡眠恢复 | 合并必要补同步，不重放全部错过的节拍，界面继续可操作 |

## 窗口、尺寸与主题

具体交互规则见 [产品设计](product-design.md)。浏览器模拟不能替代原生窗口和鼠标检查。

| 场景 | 通过条件 |
| --- | --- |
| 拖动与工作区 | 拖动中可穿过显示器共享边界，结束后完整窗口回到有效工作区；屏幕边缘打开菜单、展开和收起不裁切按钮 |
| 跨屏与展开位置 | 负坐标、错位与混合 DPI 可拖动；展开后手动移动再收起留在新屏；没有手动移动时恢复原位置 |
| 置顶入口与一致性 | 卡片、托盘及应用设置状态一致，实际窗口层级与保存值相符；切换账号不改变置顶，失败和并发不覆盖其他设置 |
| 四边四角调尺寸 | 每个方向可启动原生调整；水平和垂直操作仅改对应偏好，不与自动高度互相抢尺寸 |
| 两态与自动高度 | 小卡片和展开态分别保存逻辑尺寸；内容最低高度保证指标和按钮可见，展开内容必要时局部滚动，无根窗口滚动条 |
| 菜单与恢复 | 临时菜单扩窗不改写手动偏好，关闭恢复；没有主动移动时收起恢复原小窗位置及尺寸，主动移动后使用新位置；恢复默认同时重置两态 |
| 持久化与迁移 | 重启恢复设置，旧位置文件可迁移，未知配置版本不覆写；跨 DPI 和工作区变化后仍可操作 |
| 隐藏与托盘 | 隐藏后同步继续，布局变化不自行显示；托盘和重复启动恢复已有窗口状态，包括系统最小化场景 |
| 详情生命周期 | 最小化、恢复和关闭不影响浮窗；再打开不产生重复窗口、监听或轮询，共享当前账号 |
| 正常退出 | 托盘退出后应用及子进程结束，重启恢复账号、偏好和位置；强制终止不能计作正常退出通过 |
| 主题 | 浅色、深色覆盖全部页面和菜单；跟随系统解除显式覆盖并即时响应，跨窗口同步、重启保留，透明度不降低文字清晰度 |
| 系统兼容 | 分别验证实际 Windows 10/11、100%～200% DPI、多屏不同缩放及显示器断开重连 |

## 资源与持续运行

最终 Release 的纯空闲观察至少 60 分钟，账号正常同步、详情关闭且无用户操作；另进行至少 20 轮详情开关、账号和页面切换，再观察资源回收和请求是否重复。长期稳定性需要更长时间的分段趋势，不能只根据一次无崩溃判断。

使用现有资源脚本记录有效 CPU、主进程和进程树私有内存、进程数与实际观察时长。首次和新进程首个间隔不计算 CPU 增量；共享工作集不能当作独占内存。将纯空闲、操作、构建和探针时段分开说明，不输出业务请求或认证信息。

## 分发与升级

| 场景 | 通过条件 |
| --- | --- |
| 分发完整性 | npm、Cargo、Tauri、EXE 与安装器内部版本匹配；校验文件一致，ZIP 精确收录 EXE、使用说明及三份法律声明 |
| 当前用户安装 | 安装路径、开始菜单和卸载注册表正确；没有开发工具也能启动 |
| WebView2 | 已装运行时可启动；未装时下载与安装成功，失败或离线条件有明确结果；旧运行时兼容单独验证 |
| 安装版与 ZIP 升级 | 退出旧实例后启动确为新版；账号、偏好、主题、位置和两态尺寸按迁移规则保留 |
| 共享配置与单实例 | 同一 Windows 用户下两种分发共用配置，互相启动只保留一个实例并恢复浮窗 |
| 卸载保留 | 正常退出所有实例后默认卸载，安装入口和程序移除，共享配置可由 ZIP 继续使用 |
| 卸载清除 | 主动选择删除数据后共享账号设置清空，ZIP 再启动进入初次连接；站点数据不受影响 |

0.1.8 内置更新另按 [更新方案](plans/0.1.8-in-app-updates.md) 验证：检查失败不能显示已是最新；跳过与手动检查兼容；重复点击和迟到事件不能串状态；不完整、过大、篡改或版本不匹配的包不可安装。准备时等待在途操作并保存，失败后恢复；真实安装检查自定义含空格目录、重启、注册表版本及配置字节保留。隔离测试应用的安装成功不能代替 SubGauge 公共渠道及真实账号升级验收。

安装器只检查安装目录 EXE，升级或卸载前必须通过托盘退出另一目录的 ZIP 实例。清除数据影响两种分发的共用配置。初装、缺少 WebView2 和卸载清空使用独立 Windows 测试用户或 VM，不能用日常账号配置，也不能移除日常运行时。

报告数据存在状态、首次连接界面和版本即可；不要复制 DPAPI 配置到仓库或测试夹具。设备或环境条件不足时记录未执行，不以静态源码推断实测通过。
