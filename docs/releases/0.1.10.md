# SubGauge 0.1.10 · 体验打磨候选

2026-10-08。本地候选，尚未公开发布、推送版本 Tag 或修改在线预览清单。本轮保留现有卡片结构和全部 Key 个人汇总，不新增套餐、提醒或云同步。

## 改进

- 浮窗状态保持一行，展开后按需查看原因；用量、余额、最近窗口和最近一笔独立记录同步状态。最近窗口待补齐不再使今日完整汇总也显示不完整。
- 最近一笔显示“几分钟前”，悬停可看具体时间。小额扣费保留更多位，极小非零值显示界限；完整费用仍可在悬停或请求详情读取。
- 趋势按时段间隔排列，支持键盘与悬停读数；未确认时段和站点未提供的分桶时区明确说明，不补造零值。
- 请求页顶部使用紧凑汇总；模型、Key 可以按名称搜索、选择，候选失败仍可手填。候选按需缓存五分钟，切账号和迟到响应隔离。
- 模型与 Key 按实际扣费降序，点击进入对应请求；浮窗及顶部仍显示全部 Key 汇总。整行可展开，复制文本不触发展开。
- 设置分组、固定保存反馈、浅深色文字对比和间距统一打磨。

## 安装与验证

候选仍使用现有 Windows 用户数据目录和单实例机制。安装前从托盘退出旧实例，再运行安装包；不必卸载或删除账号数据。没有自动替换当前日常安装版。

类型、生产构建、自动回归、两个站点只读接口核对与实际 Vue 页面检查分别记录在 [验证记录](../validation.md)。真实数据的本机预览是只读快照，不代表原生新版持续同步或升级安装已验收；日常版不因预览切换主题、账号或保存操作而改变。

本地完整检查与三个隔离原生冒烟已通过；签名安装器和 ZIP 已生成并核对版本、内容与 SHA256。更新签名仍使用原公钥，安装器没有 Windows Authenticode 证书签名。文件校验值和测试限制见验证记录，重新构建后须重新计算，不复用旧 Hash。

Windows 11、实际双屏/混合 DPI、真实账号升级、新版长期资源观察与原生鼠标体验仍须对应环境实测。公开发布前还需完成候选安装验收、固定源码、GitHub CI、附件下载回查和更新清单核对，不使用本地构建成功代替这些环节。
