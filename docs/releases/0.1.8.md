# SubGauge 0.1.8 · Windows x64 预览版

加入内置更新，并包含 0.1.7 的置顶与跨屏窗口改进。[v0.1.8 预览版](https://github.com/YuVerseX/SubGauge/releases/tag/v0.1.8) 已于 2026-10-03 公开，固定二进制源码提交为 `704fc14e526161eb408ee402c819f9e7e2077098`；[Windows CI](https://github.com/YuVerseX/SubGauge/actions/runs/37123263193) 全部通过。

## 改进

- 详情应用设置与托盘提供检查更新；默认最多每日检查，可以关闭或跳过某个版本。
- 安装版确认下载，完整验证包签名与版本后，再确认安装并重启；不自行下载或重启。
- 有界下载、进度、互斥与迟到状态处理；网络、签名或保存失败明确提示，可以重试。
- 安装前等待在途账号操作并保存配置；NSIS 保留当前自定义目录与用户数据。安装器启动后不保证自动回滚。
- 免安装版进入发布页下载 ZIP，开发版不启动安装器。
- 浮窗图钉、托盘置顶、设置局部更新与跨屏拖动生命周期，详见 [0.1.7 窗口改进](0.1.7.md)。

## 附件与升级

六个附件已公开并匿名下载回查：`SubGauge_0.1.8_x64-setup.exe`、对应 `.sig`、`SubGauge-0.1.8-windows-x64.zip`，以及三者的 `.sha256`。实际字节、服务器摘要、尺寸与本地构建一致，公开下载的安装器签名验证通过。预览清单 `updates/preview.json` 已部署；构建仍只生成忽略目录的待审清单，不自动公开。

运行需要 WebView2 Runtime。安装器没有 Windows Authenticode 证书签名；`.sig` 是内置更新使用的独立 Minisign 签名，不能消除 Windows 未知发布者提示。两种分发共用当前 Windows 用户的数据及单实例机制。

0.1.6 与 0.1.7 没有内置更新，第一次升级需从托盘退出旧实例，再手动安装 0.1.8 到原目录。0.1.8 安装版可检查已公开的预览渠道，日后新版签名附件和清单发布后可内置升级；ZIP 继续手动解压。操作与失败恢复见 [使用说明](../user-guide.md)。

## 验证范围

自动回归覆盖现有统计、会话、窗口与主题，并增加更新交互、签名、可信版本、偏好、在途操作等待和失败恢复。隐藏原生窗口测试验证实际 updater 检查、下载和准备失败后的恢复；独立测试应用完成官方 updater 与 NSIS 的真实升级，保留含空格自定义目录、配置字节、注册表版本和自动重启。

独立安装测试应用没有真实账号，不代替 SubGauge 的实际账号升级；该项、实际双屏与混合 DPI、Windows 11、新版长期资源观察仍待验收。最终检查数量、公共渠道验证和校验值见 [验证记录](../validation.md)。本次发布没有替换用户日常安装版。
