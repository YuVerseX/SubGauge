# SubGauge 0.1.6 · 预览版

这是 Windows x64 的早期预览版本。[源码](https://github.com/YuVerseX/SubGauge)、安装与验证说明均已提供；软件下载附件使用安装包或免安装 ZIP。公开发布状态以 [GitHub Releases](https://github.com/YuVerseX/SubGauge/releases) 为准。

## 功能

SubGauge 是 Windows 桌面 Sub2API 个人用量悬浮窗。通过站点地址、邮箱和密码连接账号，支持多站点、多账号；普通用户和管理员都查看自己账号下全部 Key 的合计，不要求 API Key。

- 今日、滚动最近 7 天、自然月和最近 N 分钟，显示实际扣费、请求数、Token、加权缓存率及当前余额。
- 精简卡片常驻，原地展开；详情提供趋势、请求筛选与分页、模型和 Key 分析。
- 账号独立保存指标、顺序、默认范围、时区和最近窗口时长。
- 拖动定位与拖边调尺寸，隐藏到托盘、详情最小化；浅色、深色和跟随系统主题。
- 支持 TOTP 流程及会话恢复；记住登录使用当前 Windows 用户范围 DPAPI 加密，不持久化密码。

最近 7 天为连续 168 小时，余额始终为当前快照；不额外计算套餐账期或跨站费用合计。

## 本版修复

- 筛选或后续页返回概览时，不再显示上一查询的记录；读取失败和迟到响应有对应回归。
- 保存账号显示设置后的成功提示正常显示，后续普通切页清除旧提示。
- 保存偏好期间同账号重新登录时，旧会话保存明确提示重试，避免默认范围与当前范围不一致。
- 整理公开文档、MIT 许可证、贡献与安全指南、Issue/PR 模板和 Windows CI。
- 安装版和 ZIP 随附项目、第三方及 Rust 标准库声明；新增生成与校验流程，来源或内容变化时阻止打包。

## 分发与运行

候选附件如下；安装包与 ZIP 分别附带 SHA256 校验文件。

| 文件 | 用途 |
| --- | --- |
| `SubGauge_0.1.6_x64-setup.exe` | Windows x64 当前用户安装版 |
| `SubGauge-0.1.6-windows-x64.zip` | 免安装版，解压后运行 `SubGauge.exe` |
| `SubGauge_0.1.6_x64-setup.exe.sha256` | 安装包校验值 |
| `SubGauge-0.1.6-windows-x64.zip.sha256` | ZIP 校验值 |

运行需要 WebView2 Runtime。安装版发现缺少运行时时会联网下载；免安装版需提前准备运行时。当前分发未签名。

两种分发共享当前 Windows 用户的账号和设置。升级前从托盘选择“退出 SubGauge”，再安装或启动新版；旧实例仍运行时，新版启动会恢复旧实例。免安装不表示凭据可以跨 Windows 用户或跨电脑迁移。详细操作见 [使用说明](https://github.com/YuVerseX/SubGauge/blob/main/docs/user-guide.md)。

## 已验证与待验证

0.1.6 通过类型检查、生产前端构建、202 项布局回归、7 项详情回归、49 项 Rust 回归、格式与严格 Clippy。Release 和安装器内部版本一致，ZIP 内容及两种分发的 SHA256 已核对。

既有桌面实测基线为 0.1.5 / Windows 10 x64 / 150% 显示缩放；0.1.6 尚未重做安装升级与原生桌面验收。两个 Sub2API 部署的管理员和普通用户已核对个人登录、余额和用量，但不代表所有定制部署均兼容。

首次远端 Windows CI 已完成检查与构建；新增分发材料的实际验证结果以验证记录为准。Windows 11、其他实际 DPI、多屏、真实验证码与 TOTP、长期内存稳定性仍待验证。浏览器示例回归不替代原生桌面验收。完整证据和实现上限见 [验证记录](https://github.com/YuVerseX/SubGauge/blob/main/docs/validation.md)，源码与声明来源见 [来源与致谢](https://github.com/YuVerseX/SubGauge/blob/main/ACKNOWLEDGEMENTS.md)。
