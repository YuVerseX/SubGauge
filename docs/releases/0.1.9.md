# SubGauge 0.1.9 · Windows x64 预览版

增加登录 Windows 后自启、启动方式、全局浮窗快捷键和同步提示。[v0.1.9 预览版](https://github.com/YuVerseX/SubGauge/releases/tag/v0.1.9) 已于 2026-10-04 公开，固定二进制源码提交 `26d6da401aebe4143285d3aae9d7c4453ad166ae`；该提交的 [Windows CI](https://github.com/YuVerseX/SubGauge/actions/runs/37197619149) 已全部通过。没有覆盖旧附件或移动旧 Tag。

## 日常使用

- “详细用量 → 应用设置 → 启动与快捷键”中开启登录自启，并选择显示浮窗或仅进入托盘；默认关闭自启。
- 安装版登记当前用户实际程序路径；免安装版不修改安装版的启动项。Windows 可以单独禁用已登记项目，设置提供系统入口，不自动覆盖用户的禁用选择。
- 全局显示/隐藏快捷键默认关闭，可自定义，例如 `Ctrl+Alt+G`。注册冲突时保留旧键，重启恢复失败不阻断其他启动设置保存。
- 同步状态悬停可查看用量、余额、最近窗口各自的时间和数据年龄；长时间无更新会自然标记过期。
- 指标悬停显示完整费用、Token 构成、请求数及缓存率分母；费用提示保留服务端原始精度，卡片尺寸不因此膨胀。

## 升级与卸载

六个附件已上传并匿名下载回查，内容、GitHub digest、尺寸、更新签名与本地构建一致。预览更新清单已指向 0.1.9；0.1.8 安装版可在“软件更新”或托盘检查更新，主动下载并确认安装，免安装版继续下载 ZIP。

运行需要 WebView2 Runtime。更新签名使用 Minisign，安装器仍无 Windows Authenticode 证书签名；两种分发共享当前 Windows 用户的数据和单实例机制。

内置更新继续使用签名校验和原目录 `/UPDATE` 安装，保留登录启动登记。普通卸载只清理指向当前安装目录的 `SubGauge.Desktop` 启动值，不删除其他目录的值或用户数据。手动安装若选择先卸载，视作普通卸载，自启需要安装后重新开启。

设置保存于当前用户的 `desktop.v1.json`，不含凭据。仅进入托盘只影响登录启动，手动打开和更新后重启会显示浮窗。免安装文件夹移动后，快捷键在下次运行时按新进程恢复，自启仍不开放。
