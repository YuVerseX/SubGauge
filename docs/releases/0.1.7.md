# SubGauge 0.1.7 · 候选版

本版改善浮窗置顶入口与跨屏拖动。目前为本地候选包，尚未公开发布；实际双屏和升级验收仍待完成。

## 改进

- 浮窗底部增加图钉，可直接切换置顶；托盘增加可勾选的“浮窗置顶”，与详情应用设置同步。
- 拖动期间暂停程序位置校正，结束后按落点屏幕及其工作区调整、保存，解决旧逻辑在屏幕接缝把窗口拉回的问题。
- 展开态移动后再收起，小窗留在新位置；未移动的展开收起继续恢复原位置。
- 采用系统移动/缩放消息处理手势，覆盖前端拖动柄、原生外侧边框及系统菜单入口；移除旧鼠标按键轮询。
- 应用设置只保存改动字段，避免置顶、主题或刷新间隔互相覆盖；并发编辑同一字段时提示重新确认，操作失败时报告实际状态。

## 候选附件

| 文件 | 用途 |
| --- | --- |
| `SubGauge_0.1.7_x64-setup.exe` | Windows x64 当前用户安装版 |
| `SubGauge-0.1.7-windows-x64.zip` | 解压后运行 `SubGauge.exe` |
| 同名 `.sha256` 文件 | 对应附件的 SHA256 校验值 |

运行需要 WebView2 Runtime，分发未签名。安装版和 ZIP 共用当前 Windows 用户的数据目录及单实例机制；账号、设置和窗口配置沿用原格式，不迁移到安装目录。

升级前从托盘选择“退出 SubGauge”，再安装候选版；安装时确认使用已有目录。旧实例未退出时，启动新版会恢复旧实例。免安装凭据不能直接跨 Windows 用户或电脑迁移。具体操作见 [使用说明](../user-guide.md)。

## 验证范围

类型检查、生产前端构建、202 项布局回归、25 项详情和交互回归、62 项 Rust 回归、格式和严格 Clippy 通过。另行执行的隔离原生冒烟通过，验证真实 HWND 置顶标记、手势消息处理和监听销毁；使用隐藏窗口，不占用桌面鼠标或真实账号。

安装包与 ZIP 构建通过，版本、随附文档和声明、包内文件及 SHA256 校验文件已核对。候选附件不包含账号或应用配置。

几何回归覆盖相邻屏幕、负坐标、错位和布局空白区，但不代表实际双屏已验收。实际双屏、混合 DPI、Windows 11、热插拔、0.1.6 升级及公开 CI 尚未验证。详细结果和本次附件校验值见 [验证记录](../validation.md)。
