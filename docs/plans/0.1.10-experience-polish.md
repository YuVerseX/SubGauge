# 0.1.10 日常体验打磨

日期：2026-10-08。状态：实现、本地检查、Windows CI 与公开发布完成，内置更新清单已上线；实际升级过程与原生交互仍按验证范围验收，结果见 [验证记录](../validation.md)。

## 范围与依据

基于 0.1.9 各页面、浅色/深色以及两个真实账号今日数据的只读审查。保留常驻卡片、原地展开、三个用量页面和独立账号偏好的结构。这轮解决可读性、操作步骤和统计表达，不新增套餐计算、提醒、云同步或更多常驻指标。

1. **浮窗与数字**：保持两列指标与现有尺寸行为；状态占用固定一行，详细原因按需查看；区分当前范围、余额、最近窗口的完整性；最近一笔显示相对时间并提供完整时间；小额非零费用不舍入成零。
2. **趋势**：按实际时间间隔排列柱形，简化刻度，悬停与键盘均可查看精确值；确认分桶时区/覆盖范围前不把未知时段填成零。取数失败、不完整与零用量分别表示。
3. **记录与分析**：记录页上方改为紧凑的全部 Key 汇总；模型与 Key 支持按名称搜索选择，兼容手填模型及 Key ID；筛选不影响卡片。模型/Key 按费用降序，点击项目进入对应记录；列表支持整行展开，选中文本不触发展开，空筛选明确说明。
4. **设置与视觉**：沿用蓝灰、白色及深蓝灰两套配色。数据数字使用现有 Bahnschrift，正文与控件沿用系统字体；详情正文/辅助文字适当增大、加强浅色对比。设置分组紧凑排列、低频说明按需展开，保存反馈始终在操作附近可见。账号管理、连接页仅做一致性打磨。

## 实现边界

- Rust 管理状态、认证与筛选选项；前端不持有令牌。个人 Key 列表只返回 ID 与名称，不向前端传递密钥字段。
- 分项同步状态兼容旧配置，历史不完整状态不能被迁移为完整。失败保留旧值并显示范围明确的状态；分项成功不抹掉其他分项失败。
- 筛选和分析响应携带账号/范围，切换账号、范围或页面后拒绝迟到结果；筛选选项按需缓存，不增加常驻轮询。
- 数字改动只影响显示，不改变十进制费用、Token 或缓存率计算。
- 图表不假定两个部署版本具有相同分桶时区；没有可靠依据的间隔显示为未知，不能补造数据。
- 开发与页面复查不改正在运行的安装版、真实账号偏好、启动项或在线更新清单。公开发布获授权后，按发布流程验证附件并上线清单。真实用量仅用于本机只读复查，不进入仓库、截图文档或分发包。

## 顺序与验收

1. 明确后端兼容字段和候选接口，保留关键统计/并发回归。
2. 完成卡片、图表、筛选、排序跳转与设置反馈，集成同接口示例适配器。
3. 运行类型检查、生产构建、现有布局/详情/桌面/状态/更新检查，以及 Rust 格式、Clippy 和测试；新增状态隔离、时间轴、极小费用、筛选键盘和迟到响应回归。
4. 用实际页面逐页检查浅色/深色、窄窗口、长名称、空数据与失败状态；用真实数据只读复查。浏览器与原生测试分开记录，无法执行项不记为通过。
5. 更新版本、使用说明、变更与验收记录；构建 Windows 安装包和免安装 ZIP，核对版本、签名和内容。公开发布与安装验收按发布流程记录，不能用构建成功替代。
