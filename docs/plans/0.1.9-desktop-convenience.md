# 0.1.9 启动与日常使用优化

日期：2026-10-04。状态：功能、完整回归、隐藏原生与卸载 hook 检查已完成，分发及远端发布核对进行中；完成范围以 [验证记录](../validation.md) 为准。

## 本版范围

1. 应用设置增加“启动与快捷键”，仅用户保存后改变系统设置。
2. 安装版可登记当前 Windows 用户的登录启动项，默认关闭。启动方式可选显示浮窗或仅进入托盘，默认显示浮窗；该选择只影响带 `--autostart` 的登录启动。手动启动、更新重启仍显示浮窗。重复登录启动不打扰已有实例。
3. 全局快捷键默认关闭，可设置 Ctrl/Alt/Shift 加字母、数字或 F1～F11；至少含 Ctrl 或 Alt。不占用 Windows 键、F12 或无修饰键。冲突明确提示，失败不替换原快捷键。安装版及免安装版可使用，开发模式不自动注册。
4. 卡片沿用现有布局：同步状态悬停说明用量、余额、最近窗口各自的更新时间；已同步结果自然过期时显示“数据未更新”。费用、Token 和缓存率提供完整数值提示，保留服务端费用字符串。

## 原生边界

- 使用当前用户 `Run` 的 `SubGauge.Desktop` 值，登记带引号的实际可执行文件路径和固定 `--autostart` 参数；不需要以管理员身份运行，不写全局启动项。
- 不在加载设置、应用启动、升级或轮询时重新登记自启；尊重 Windows 中禁用的选择，不修改 `StartupApproved`。注册与系统实际允许启动分别描述，未知状态不宣称启用；不依赖未公开的二进制批准状态格式，提供 Windows 启动设置入口。
- 安装版升级沿用原目录与原启动值；NSIS `/UPDATE` 不清理启动值。真正卸载只删除指向当前卸载目录的本应用值，保留其他目录的登记与用户数据。
- 免安装版不修改安装版的启动项；展示受限原因。开发预览使用明确的示例状态，不注册真实快捷键或自启。
- `desktop.v1.json` 保存启动方式、快捷键，采用版本化原子写入，不含账号凭据；损坏或未来版本配置保留文件并说明原因。自启登记以系统实际状态为准。
- 设置保存串行处理、带 revision；另一窗口或外部启动状态变化后拒绝旧草稿覆盖。先保留原快捷键并尝试登记新键，持久化或启动项变更失败时回滚。
- 快捷键仅处理按下、禁止自动重复，沿用当前窗口消息循环；退出释放注册。按键显示时重新检查屏幕工作区，不修改统计范围。

## 同步提示

已有同步失败、部分数据和需登录状态优先保留。正常状态按当前可见指标检查对应时间；阈值至少 90 秒或对应刷新间隔的三倍，避免在正常刷新间隔内误报。最近范围额外检查最近记录时间，余额使用独立时间。缺失、非法和明显未来时间保守显示，不能把不完整结果标为已同步。仅更新提示，不自行增加接口轮询。

## 验证与交付

- 保留自启命令、启动来源、快捷键解析与冲突、保存失败回滚、多窗口代次、过期提示的业务回归。
- 运行现有前端、布局、详情、更新、签名和 Rust 检查，新增面板使用隔离浏览器模拟。
- 原生验证使用隐藏窗口、独立注册表键和独立数据目录；不读日常账号、不改变用户真实自启项、不占用用户鼠标。检查实际快捷键冲突、窗口显隐与清理。
- 构建带签名的 NSIS 与免安装 ZIP，验证自启 hook 的安装/升级/卸载行为以及目录含空格；不覆盖 0.1.8 已公开附件。
- 当前电脑的真实登录自启、主应用更新安装、实际双屏/混合 DPI 和 Windows 11 需实际设备操作，未执行则明确记录，不用隔离测试替代。

余额/用量提醒、筛选选择列表、更多布局、云同步不包含在本版。
