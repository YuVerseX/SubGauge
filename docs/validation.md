## 实现边界

- 默认账号统计时区为 `Asia/Shanghai`，可修改；服务端图表分桶标签时区仍未验证。
- 汇总边界明细和 Key 分析最多读取 5,000 条、最多两次覆盖确认；不完整时明确标记，不能作为最终总计。请求列表采用独立分页，可翻到该数量之后。
- 滚动列表翻页沿用固定范围，上下文有效 60 秒；过期或记录变化时需刷新第一页。
- 图表按需读取，缓存最多 5 分钟；强制刷新不越过账号限流等待期。本月汇总不周期拉取整月明细。
- `Retry-After` 仅支持整数秒；请求不主动取消，通过账号、运行时、范围和代次拒绝过时结果。
- 没有 Windows Authenticode 证书签名；0.1.8 的内置更新采用独立 Minisign 签名。没有套餐结转、跨站费用合计、云同步或全量历史数据库。
