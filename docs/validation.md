# SubGauge 验收摘要

整理日期：2026-10-02；当前源码：0.1.6；既有桌面验收基线：0.1.5。本页区分既有实测与当前源码检查。自动回归、隔离原生 API、用户实际操作和部署核对分别记录，不能互相替代。

## 0.1.6 修复与源码检查

当前源码的 `npm run verify` 通过：Vue/TypeScript 类型检查、生产前端构建、202 项布局回归、7 项详情回归、Rust 格式、严格 Clippy 和 49 项 Rust 回归。本次未改变依赖；上次整理时 `npm audit` 没有报告已知 npm 依赖漏洞，此结果不覆盖 Rust 依赖或全部安全问题。

当前文件已检查六处版本一致性、文档本地链接和隐私模式，未检出已知真实站点、个人邮箱或 JWT 模式；GitHub 上传准备另复核了可达 Git 历史的文件与提交署名，未检出已知隐私模式或应忽略的生成文件。该模式检查不是完整安全审计。仓库已重新初始化，首次提交仅包含审查后的文件；旧 Git 备份位于项目外，旧导出包和临时记录已清理。README 两张截图已逐张查看，仅使用明确标注的示例数据。

本次没有重做真实站点与原生桌面验收，也没有替换既有安装的 0.1.5。两类本机浏览器回归均使用实际 Vue 页面、Tauri 官方 IPC 模拟和无头 Edge，不操作桌面鼠标；Rust 回归使用隔离夹具。

公开仓库首次 [Windows CI](https://github.com/YuVerseX/SubGauge/actions/runs/37017693554) 在提交 `7218a78` 上全部通过：Windows Server 2022、Node.js 24.20.0、Rust 1.99.0 和无头 Chromium，覆盖 202 项布局、7 项详情、49 项 Rust 回归、格式、严格 Clippy、安装包和 ZIP 构建。该提交尚未包含本次新增的分发声明，其构建不能作为新包装内容的验证。

此前 `npm run package` 和 `npm run package:portable` 已通过，0.1.6 Release EXE 与 NSIS 的内部版本一致。本次新增声明后正在重新构建，旧 ZIP 的两文件核对不沿用为新包验收。产物位于 Git 忽略的 `release/`，没有加入源码提交。这些检查不代表 0.1.6 安装升级或原生运行已验收。

前端永久回归先在原逻辑运行，7 项中 3 项失败，分别复现加载中残留、失败后残留和保存成功提示消失；修复后 7 项全通过。延迟请求由测试显式释放，避免依赖固定等待时间。

Rust 竞态回归先在原逻辑失败：旧保存成功却返回默认月范围、当前今日范围。修复后该用例及正常保存、重启持久化用例通过，并纳入 49 项全量回归。竞态由持有旧缓存锁、确定性推进保存到等待点、替换运行时再释放锁构造，没有调用真实站点。锁顺序复核未发现新增反向等待。

## 验证环境

主要实测环境为 Windows 10 Pro x64（19045）、已安装 WebView2、150% 实际系统缩放。Windows 11、其他实际 DPI 和多屏尚未完成验收。浏览器检查中的 100%～200% 为模拟像素比例，不表示对应 Windows 系统 DPI 已通过。

## 个人接口与统计核对

| 部署 | 既有核对范围 |
| --- | --- |
| 部署 A：管理员账号 | 邮箱登录、个人余额与用量接口、加密会话重启恢复，以及已结束日期的汇总和完整分页明细 |
| 部署 B：普通用户账号 | 邮箱登录、个人余额与用量接口，以及已结束日期的汇总和完整分页明细 |

两部署分别按同一账号、时区和范围核对，费用、四项 Token 及加权缓存率与完整明细一致；余额更新后与个人接口一致。管理员核对使用个人接口，没有以全站统计代替个人用量。样本各只有一个不同 Key，不能据此宣称实际多 Key 已验证。

活跃日期存在新增请求和采样时间差；服务端没有提供多个接口的严格事务快照。普通用户结果不能推导为所有定制部署均受支持。真实站点启用 TOTP、验证码挑战及延迟落库场景仍待验证。

## 持续运行与资源

0.1.4 的两个账号持续运行观察约 60 分钟，应用保持响应，没有观察到持续 CPU 忙循环或崩溃；后半段内存增速放缓，但均值仍有增长。观察期间包含其他构建和检查，没有独立确认用户全程无操作，因此不是严格纯空闲基线，也不能证明长期没有泄漏。

该记录不能沿用为 0.1.5 或 0.1.6 的长期稳定性通过。资源观察已结束，本次修复没有新增或延长采样。进程树工作集可能重复计算共享页，不能直接当作独占内存。

## 实现边界

- 默认账号统计时区为 `Asia/Shanghai`，可修改；服务端图表分桶标签时区仍未验证。
- 汇总边界明细和 Key 分析最多读取 5,000 条、最多两次覆盖确认；不完整时明确标记，不能作为最终总计。请求列表采用独立分页，可翻到该数量之后。
- 滚动列表翻页沿用固定范围，上下文有效 60 秒；过期或记录变化时需刷新第一页。
- 图表按需读取，缓存最多 5 分钟；强制刷新不越过账号限流等待期。本月汇总不周期拉取整月明细。
- `Retry-After` 仅支持整数秒；请求不主动取消，通过账号、运行时、范围和代次拒绝过时结果。
- 分发未签名；没有套餐结转、跨站费用合计、自动更新、云同步或全量历史数据库。
