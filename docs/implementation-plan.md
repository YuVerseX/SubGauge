# SubGauge 架构与数据约定

SubGauge 使用 Tauri 2、Vue 3、TypeScript 和 Rust，面向 Windows x64。前端负责呈现与交互；原生核心集中管理账号、请求、统计、存储、同步和窗口。安装版与 ZIP 使用相同应用标识 `app.subgauge.desktop`，共用当前 Windows 用户的数据目录和单实例机制。

用户操作见 [使用说明](user-guide.md)，开发命令见 [开发文档](development.md)，统计接口的源码依据见 [接入研究](integration-notes.md)。实际兼容与未测边界统一记录在 [验收摘要](validation.md)。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `src/App.vue`、`src/components/` | 卡片、详情、登录、设置和展示组件 |
| `src/api.ts`、`src/types.ts` | 类型化命令、原生 DTO 转换与跨窗口事件 |
| `src/demo.ts` | 显式示例适配器，不接收真实凭据 |
| `src-tauri/src/lib.rs` | Tauri 命令、托盘、单实例与共享同步调度 |
| `src-tauri/src/windows.rs`、`windows_tests.rs` | 原生窗口、工作区、两态尺寸、菜单临时扩窗、持久化与回归 |
| `src-tauri/src/core/mod.rs` | `Engine` / `Runtime`：账号、会话互斥、统计、分页、缓存和同步状态 |
| `src-tauri/src/core/client.rs` | HTTP、认证、刷新、超时、限流及重定向限制 |
| `src-tauri/src/core/stats.rs` | 时区边界、十进制费用、Token 与加权缓存率 |
| `src-tauri/src/core/storage.rs` | Windows 用户范围 DPAPI 与配置原子写入 |
| `src-tauri/src/core/types.rs`、`tests.rs` | 内部接口与关键业务回归 |

所有窗口共用同一个原生服务，不各自轮询。卡片和详情共享当前账号；详情的 Key、模型筛选只作用于明细与分析，不改变卡片的全部 Key 汇总。

## 账号与会话

账号身份为规范化站点地址加服务端用户 ID，别名和邮箱不作为跨站身份索引。普通用户和管理员默认都读取当前登录账号自己的个人接口，不将管理员全站或上游账号池统计作为默认来源。

支持邮箱密码、TOTP、刷新互斥、过期重登和重启恢复。登录成功后保存账号，失败不覆盖已有连接；密码不持久化。记住登录使用当前 Windows 用户范围 DPAPI，令牌只由原生核心管理，不进入前端 Bootstrap。

站点地址不能包含凭据、查询参数或片段；带认证请求不跟随重定向。错误不回传任意服务端文本，日志不包含认证载荷。验证码挑战不受支持时明确提示，不绕过验证或自动改为必须使用 API Key。

请求不主动取消；账号运行时、范围、偏好和请求代次检查用于拒绝过时结果，避免重新登录、切换账号或变更范围后被旧响应覆盖。前端没有接收任意 URL 与认证头的通用代理命令。

## 数据与存储

`AccountSummary`、`AccountPreferences`、`UsageSnapshot`、`UsageRecord` 和 `SyncStatus` 是共享数据类型。结果携带账号、范围、代次及同步信息；费用在原生统计中使用十进制值，显示舍入不改变统计口径。

配置位于 `%LOCALAPPDATA%\app.subgauge.desktop`：

- `accounts.v1.json` 保存账号偏好、应用主题、加密会话和最后成功快照。
- `window.json` 保存位置，以及小卡片和展开态各自的逻辑尺寸；旧物理位置配置按迁移规则保留位置并恢复默认尺寸。

文件使用版本化格式与原子替换。未知版本或损坏文件保留并报告错误；单账号会话解密失败时要求重新登录。DPAPI 不支持直接跨 Windows 用户或电脑迁移，也不阻止以相同 Windows 用户身份运行的程序访问数据。

缓存有界，不保存全量历史数据库。浏览器示例必须显式 `?demo=1`，桌面示例由用户主动开启；真实连接失败不回退为模拟数值。

## 统计口径

| 范围 | 定义与实现 |
| --- | --- |
| 今日 | 账号时区今日零点起，指定日期与时区读取个人汇总 |
| 本月 | 账号时区本月 1 日零点起，显式日期查询，不使用滚动月份的 `period=month` |
| 最近 7 天 | 连续 168 小时；完整中间日期汇总加两侧边界明细 |
| 最近 N 分钟 | 默认 5 分钟；完整覆盖明细后按 `[start, end)` 时间窗口筛选 |

账号统计时区默认 `Asia/Shanghai`，可修改。费用使用 `actual_cost`；Token 为普通输入、输出、缓存读取和缓存写入之和。缓存率为缓存读取 /（普通输入＋缓存读取＋缓存写入），按输入 Token 加权，分母为零显示“—”。余额是独立的当前快照。

余额、范围用量和最近记录分别保留同步时间。接口读取期间可能有新请求入账，多接口不是服务端事务快照；服务端趋势分桶标签的时区仍需部署核对。

滚动明细列表通过边界排名和目标页读取，翻页沿用固定窗口，上下文有效 60 秒；过期或记录变化时提示刷新第一页。此列表可以翻到 5,000 条以后。

汇总边界明细和 Key 分析的单次覆盖上限为 5,000 条，最多两次覆盖确认。无法确认完整范围时标记不完整，不把局部数据当最终总计。本月汇总不周期拉取整月明细，Key 分析按需读取。

## 同步与缓存

| 类别 | 默认策略 |
| --- | --- |
| 当前账号最近请求 | 10 秒 |
| 当前账号余额与范围汇总 | 30 秒 |
| 后台账号 | 120 秒 |
| 图表与分析 | 按需读取，缓存最多 300 秒；手动刷新绕过缓存 |
| 失败与限流 | 指数退避；记录、分析和后台共用账号等待期，强制刷新也不越过等待期 |

刷新间隔可设置。原生定时器跳过错过的节拍，账号刷新互斥避免积压。`Retry-After` 支持整数秒，HTTP 日期格式尚未支持。失败时保留最后结果并标记状态；无法确认完整覆盖时显示不完整。

## 窗口与外观

浮窗原地展开收起，小卡片和展开态分别保存逻辑宽高；手动高度与内容最低高度分开，内容临时撑高不改写偏好。菜单按可用空间临时扩窗，关闭恢复，菜单展开期间不允许拖边。

位置和尺寸受屏幕工作区限制；DPI 或显示器改变时按逻辑尺寸重新计算并限制在可操作区域。详情按需创建、关闭后释放。隐藏或最小化继续同步，托盘和重复启动恢复已有实例；退出从托盘完成。

浅色、深色和跟随系统属于应用设置，跨窗口同步并持久化。跟随系统解除显式原生主题覆盖，媒体变化只更新页面。透明度只影响浮窗背景，不降低文字和菜单清晰度。

不包含套餐结转、跨站费用合计、自动更新、云同步或全量历史数据库。兼容与稳定性验收按 [验收清单](acceptance-plan.md) 执行，未执行项目保持明确标记。
