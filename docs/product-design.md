# SubGauge 产品与交互设计

更新日期：2026-10-03。

本文描述产品规则；需求清单不表示全部验收通过。实现结构见 [架构说明](implementation-plan.md)，实际证据见 [验证记录](validation.md)。技术路线为 Tauri 2 + Vue 3 + TypeScript + Rust。

## 1. 产品目标与范围

让用户在 Windows 桌面随时看到关心的 Sub2API 用量，需要时再查看明细。

使用场景包括自建站的管理员账号，以及购买上游服务的普通用户账号。两者默认都统计当前登录账号的全部 API Key，不自动切换为全站或上游账号池统计。

产品能力：

- 站点地址、邮箱、密码登录，不要求先取得 API Key。
- 多站点、多账号切换；每个账号保存独立的默认周期、常驻指标和顺序。
- 常驻小卡片，默认完全不透明，透明度可设置。
- 卡片原地展开，没有主动移动时收起恢复原尺寸和位置；主动移动后保留新位置。
- 展开卡片显示最近一笔、滚动最近几分钟，并提供详细用量入口。
- 详情提供用量概览、请求记录、用量分析。
- 指标包括实际扣费、请求数、Token、缓存率和当前余额，可选择与排序。
- 统计范围为今日、最近 7 天、本月、最近几分钟；最近一笔不再作为范围选项。

当前不增加套餐周期、结转或额度预测模块；通过上游账号本身的余额和用量满足观察需求。不同站点不合计费用，避免同一转发请求重复记账。

## 2. 信息层级

### 常驻小卡片

顶部：账号别名与切换入口、统计范围、当前账号显示设置及隐藏到托盘按钮。

主体：仅展示已选指标；数值突出，标签和单位弱化。根据指标数量紧凑排列，不为未选指标预留空白位置。

底部：同步状态与展开按钮。平时不展示长域名、邮箱、身份标识、图表或账号管理列表。

按使用场景建议的配置（用户手动设置，不自动按角色套用）：

| 账号场景 | 默认范围 | 默认指标 |
| --- | --- | --- |
| 自建站 | 今日 | 扣费、请求、Token、缓存率 |
| 上游服务 | 最近 7 天 | 当前余额、扣费、Token、缓存率 |

新建真实账号统一从“今日＋扣费、请求、Token、缓存率”开始。配置针对具体账号保存，用户可以自行将上游账号改为七天并加入余额；示例适配器展示了两种配置。

### 原地展开

保留常驻指标，下方增加：

1. 最近一笔：时间、模型、实际扣费、Token、缓存率。
2. 近 N 分钟：扣费、请求数、Token 汇总；N 默认 5，允许设置。
3. 当前站点与“我的全部 Key”范围说明。
4. 详细用量入口。

最近一笔始终独立于顶部统计范围。主范围已为近 N 分钟时，可省略重复的近 N 分钟汇总，但保留最近一笔。

靠近屏幕边缘时向有空间的方向展开；记录展开前的矩形，没有主动移动时收起恢复。展开后主动移动会更新小窗位置基准。拖动期间允许跨屏，结束后按目标屏幕工作区校正；多显示器或 DPI 改变后保持窗口可操作。

### 详细用量窗口

共用顶部账号切换入口。页面始终明确当前站点、当前账号和筛选范围。

- 用量概览：范围内四项用量指标、独立的当前余额、近 N 分钟概况、消耗趋势、Token 构成、最近请求。
- 请求记录：按时间浏览，按 Key 和模型筛选，分页；点开记录查看输入、输出、缓存读写及费用。筛选不会悄悄改变常驻卡片的全部 Key 范围。
- 用量分析：按模型和 Key 展示范围内费用及用量分布；沿用同一统计口径。

从展开卡片打开详情时，继承当前账号与统计范围。“返回浮窗”恢复原浮窗状态；随后收起恢复小窗。

## 3. 多账号与登录

账号身份由规范化站点地址及站点返回的用户 ID 确定；显示别名不作为数据或凭据的索引。同一邮箱在不同站点是不同账号。

点击账号名显示选择列表：别名、域名、角色、当前标记和账号管理入口。切换后卡片与详情一起切换，并恢复目标账号的默认范围与指标。

首版交互规则：

- 添加账号填写别名、站点地址、邮箱和密码；身份由站点识别，不要求用户选择管理员模式。
- 支持站点启用的二次验证；验证码挑战的兼容方式需接入验证。
- 登录成功后才保存新账号；失败不覆盖已有账号或凭据。
- 普通用户不调用管理员接口；管理员默认也走个人用量接口。
- 一个账号失效不影响其他账号；账号列表明确显示待登录或同步失败状态。
- 不保存明文密码；需要持久化的会话凭据使用 Windows 安全存储。
- 日志、错误提示和界面不输出密码、Token、Cookie 或认证头。

## 4. 时间与统计口径

| 范围 | 定义 |
| --- | --- |
| 今日 | 所选统计时区今日 00:00 至当前 |
| 最近 7 天 | 当前时刻向前连续 168 小时 |
| 本月 | 所选统计时区本月 1 日 00:00 至当前 |
| 最近 N 分钟 | 当前时刻向前连续 N 分钟，默认 N=5 |

最近 7 天不表示套餐固定周周期；本月不表示近 30 天或订阅账期。

账户级统计时区默认固定为 `Asia/Shanghai`，可在账号显示设置中修改，用于日期边界与请求记录展示。个人接口筛选传入此时区；服务端图表分桶标签时区尚未确认，详情说明此限制。

明细计算采用开始包含、结束不包含的时间边界，分页数据按稳定记录 ID 去重。日期汇总、余额和图表分别保留采样信息；服务端多接口不保证同一事务快照，读取期间的新记录可能造成短暂差异。

指标定义：

- 扣费：个人记录中的 `actual_cost`，不混入管理员上游账号成本或标准标价 `total_cost`。
- 请求：范围内服务端已记录的用量记录数；不能宣称涵盖所有未落库的失败或进行中请求。
- Token：普通输入 + 输出 + 缓存读取 + 缓存写入；先依据部署的数据语义归一化，避免重复计算缓存。
- 缓存率：缓存读取 Token 总和 /（普通输入 + 缓存读取 + 缓存写入 Token 总和）。不包含输出，不平均每笔百分比。分母为零显示“—”。
- 当前余额：服务端当前余额快照，不受统计范围影响；不据此倒推套餐已使用额度。

默认汇总账号下全部 Key 的使用记录，包含仍保留用量记录的已删除或停用 Key，不能仅靠遍历现存 Key 计算总量。

## 5. 刷新与状态设计

“实时”指服务端用量记录更新后尽快同步，不表示请求生成过程中的逐 Token 直播。实际延迟需接入测量。

首版同步规则：

- 当前账号优先刷新，卡片和详情共享同一数据源；不各自重复轮询。
- 最近记录和余额优先于历史图表；后台账号降低刷新频率，切入时补同步。
- 轮询频率可设置；默认最近记录 10 秒、余额与范围汇总 30 秒、后台账号 120 秒，仍需根据实际接口成本和落库延迟调整。
- 单账号最多一个刷新凭据流程并发；切换时旧响应不得覆盖新账号。
- 失败退避，恢复后补齐缺失窗口；请求分页未覆盖完整区间时不能将局部数据显示为完整总计。
- 没有新请求时，滚动窗口仍随时间推进，已过期记录及时移出。

| 状态 | 界面行为 |
| --- | --- |
| 首次加载 | 占位，不能先显示为零 |
| 已同步 | 显示最后成功同步时间 |
| 无用量 | 数量和费用为零，缓存率为“—” |
| 网络失败 | 保留上次结果并标记数据未更新 |
| 部分接口失败 | 各指标说明是否为旧值，避免统一宣称已同步 |
| 登录过期 | 保留快照，提示该账号重新登录 |
| 接口或字段不支持 | 显示不可用，不伪装成零或静默更换口径 |

## 6. 视觉与窗口规则

采用简洁数字卡片：少量中性色、克制强调色、清晰数字与单位。完整窗口承载分析，常驻卡片不逐步膨胀成后台面板。

默认不透明；透明度调节只影响浮窗，不降低菜单和设置的可读性。设置同时提供指标选择、顺序、默认周期和最近窗口时长。

桌面行为包括置顶开关、拖动定位、托盘恢复。浮窗提供明确的“隐藏到托盘”按钮，隐藏后继续后台同步；托盘或重复启动恢复原状态。详情提供最小化，关闭详情只释放详情窗口；退出程序从托盘“退出 SubGauge”入口完成。

应用外观提供浅色、深色和跟随系统，默认浅色，所有窗口同步采用同一主题。主题属于应用设置，不跟随账号切换；菜单、表格、输入框、图表及状态提示使用完整主题配色。浮窗透明度只影响背景，文字与菜单保持清晰。首轮先完善同一布局的两种主题，不增加不同布局变体。

0.1.5 尺寸交互按以下规则实现，实际通过项以验证记录为准：

- 小卡片和展开态都支持拖动四边及四角，宽度默认 316 个逻辑像素，通常可在 280～640 范围调整，最终尺寸受当前屏幕工作区限制。
- 两种状态各自保存宽度和手动高度；初始高度随内容调整。仅拖动左右边保留自动高度，仅拖动上下边保留宽度。
- 小卡片最低高度完整展示所选指标及操作按钮；展开态保留固定区域并允许展开内容局部滚动。根窗口不出现横纵滚动条。
- 内容增加时实际窗口可以临时撑高，用户保存的高度不被改写；内容恢复后重新采用保存高度。
- 展开前保存小窗位置，没有主动移动时收起恢复原位置与尺寸，主动移动后使用新位置；账号菜单临时扩窗不保存成用户尺寸，菜单打开时禁止拖边。
- 尺寸按逻辑像素持久化，位置按桌面坐标恢复；DPI 或工作区变化时限制窗口在可操作区域。旧版位置文件保留位置并迁移为默认宽度、自动高度。
- 应用设置提供“恢复默认尺寸”，同时重置小卡片和展开态，不修改账号指标或范围。

## 7. 开发验收重点

- 普通用户、管理员邮箱登录均能查看自己的用量和余额。
- 同站不同账号、不同站同邮箱的数据、会话和偏好完全隔离。
- 切换账号后页面身份、数字、范围一致，慢响应不会串号。
- 今日、滚动 7 天、自然月、近 N 分钟在跨日跨月时边界正确。
- 多页数据、延迟落库、窗口过期、空数据均能正确处理。
- Token 与缓存率可由底层记录复算，与完整记录集一致。
- 余额变化不依赖统计范围，失败或旧值可被识别。
- 展开/收起和返回浮窗恢复正确；Windows 缩放与屏幕边缘可用。
- 凭据安全存储，日志脱敏；单账号重新登录不干扰其他账号。

## 9. 0.1.7 窗口改进（并入 0.1.8）

0.1.7 在卡片底部提供置顶快捷开关，并让拖动期间可以穿过当前屏幕边界。拖动结束后按目标屏幕工作区校正；展开后主动移动，再收起留在新位置。快捷入口、混合 DPI、菜单、恢复与验收规则见 [0.1.7 窗口方案](plans/0.1.7-window-controls.md)。改进已在 0.1.8 公开，实际双屏等未执行项继续单独列出，不沿用 0.1.6 的检查记录作为通过证据。

## 10. 0.1.8 内置更新（预览版）

软件更新位于详情应用设置与托盘，不增加常驻卡片指标。默认每日检查，发现新版给出版本、说明、下载和稍后或跳过操作；不自动下载或重启。安装版完整下载并验签后，由用户确认“安装并重启”；免安装版进入发布页下载 ZIP。失败保留明确状态，可重试或手动安装。完整约定见 [更新方案](plans/0.1.8-in-app-updates.md)。
